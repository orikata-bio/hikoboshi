# Provenance

The original public release was cut from Megure Labs' private development tree.
Its public Git history intentionally starts with a release-cut commit; private
development history and private execution records were not published.

Where release work was captured by Kaname, those historical records retain
their actual scope. No complete trace is claimed for uncaptured work. Existing
records and release artifacts are preserved, and missing capture is never
reconstructed or relabeled after the fact.

For public contributions, Kaname is optional. Git commits and pull requests
record authorship, relevant external materials, material AI assistance, and
actual validation. See [the public contribution policy](PROVENANCE_POLICY.md).

Historical private trace requests may be sent to `casey@megure.ai`. Availability
and access are reviewed case by case because existing records can contain
private development context and sensitive infrastructure details.

Verify release artifacts using the applicable Git tag and published checksums.
Keeping historical traces private does not change the Apache-2.0 license or
separate third-party artifact terms.

Active development is maintained at
[orikata-bio/hikoboshi](https://github.com/orikata-bio/hikoboshi).
The Megure repository preserves the earlier public history and releases.
Public model provenance remains in `data/weights/`, `weights/*.json`, and
`THIRD_PARTY_NOTICES.md`; generated embedded arrays retain their checked source
artifacts and checksum verification.
